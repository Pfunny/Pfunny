# CH.FANDRICH® KDP Toolbox

Eine einfache, lokal laufende Web-App zur Planung von Amazon-KDP-Buchprojekten.

## Aktueller Funktionsumfang

- KDP-Formatrechner von Zoll und DPI zu Pixeln
- Lokale Projektverwaltung im Browser
- Projekttypen und Bearbeitungsstatus
- Mobile, responsive Oberfläche

## Start

Den Ordner `kdp-toolbox` öffnen und `index.html` im Browser starten.

## Datenschutz

Die gespeicherten Projektdaten werden ausschließlich im lokalen Browserspeicher abgelegt und nicht übertragen.

## Geplante Erweiterungen

- Cover- und Buchrücken-Rechner
- Beschnittzugaben und Sicherheitsränder
- SEO- und Klappentext-Werkzeuge
- PDF-Prüfung
